Basic rules for Obsidian

- Never delete anything. If it's just two words, store as [[temporary]]
- Whenever possible, use pre-existing [[categories]] for notes
- Keep all notes in one folder
- Have a folder for templates, and one for [[categories]]. I want to be able to see all notes for each category in one file
- Review notes periodically. They can be filtered by whether they have been [[reviewed]] or not
